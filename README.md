# 🐱 Apiapia 学习中心 · 小朋友趣味自学平台

> 萌宠学霸猫咪 **Apiapia** 陪伴小朋友快乐学习！基于 **Cloudflare 全栈架构 (Workers + KV + Assets)** 构建的多合一轻量化自学中心，深度融合钢琴视奏与识音、日语听力假名、汉字规范笔顺听写与英语核心动词卡片。

无需自建复杂服务器，依托 Cloudflare 全球边缘网络与分布式 KV 数据库，实现：
- 🐱 **萌宠学霸猫咪伴学**：全套定制 3D 萌宠小猫咪主题视觉、高清 iOS App 图标与 Favicon，陪伴小朋友快乐启蒙；
- 🌐 **全球极速访问**：纯前端轻量化静态页面，秒级即开即学，免运维且自带免费 HTTPS；
- 🧠 **科学记忆算法**：全面采用**艾宾浩斯（SM-2）间隔重复遗忘曲线**，科学规划复习周期；
- 📱 **多端全自动同步**：手机、平板、电脑通过专属密钥（Sync Key）跨设备实时同步刷题与复习进度；
- 👶 **儿童友好护航设计**：全局 3D 立体触感大按键、统一的儿童防误触二次确认与柔和气泡提醒（`kid-dialog.js`）；
- 🏆 **100% 满分猫咪庆典奖励**：全站所有练习（汉字默写/认读/选字、假名听写、单词与句子练习、钢琴识谱）达成 100% 完全正确时，自动迸发全屏五彩礼花、喜庆和弦音效与 Apiapia 真实照片 + 3D 卡通双萌照成就勋章；
- ⚡ **SPA 单页架构与极速转场**：全站升级为 SPA 单页 App 架构，四大模块多任务保活秒开，配备萌宠「正在进入」趣味伴学卡片与动态微光进度条，转场丝滑无白屏；
- 📦 **零外部 CDN 全本地化与极速离线**：Vue 3、Vant 4、Tailwind、HanziWriter、VexFlow 与儿童字族 100% 本地自托管，彻底根治国内访问阻塞与网络波动；
- 📱 **PWA 手机/平板桌面安装**：配置 Service Worker 离线缓存与多资源预热，支持 Android 原生安装气泡与 iOS Safari 图文手把手添加到主屏幕引导；
- 🍎 **移动端 / iPad 深度适配**：支持 PWA / 添加到主屏幕全屏独立运行，针对 iOS/iPadOS Safari 视口上移、留白 bug、Web Audio 麦克风灵敏度增益与 WebKit 音频进行了全方位深度优化；
- 🔄 **自动感知平滑更新**：内置版本监测机制（当前 `v2.1.0`），新版发布后在首页无感感知并提醒一键击穿缓存刷新。

## 📚 模块功能详解

### 1. 🎌 日语听力与假名 (`/japanese`)
- **核心理念**：“听力优先”盲测设计，通过声音直接刺激大脑反应，告别“哑巴日语”。
- **三大核心功能模式**：
  - **单词听力 (Word Practice)**：2039 个核心高频词汇盲听测试（涵盖 N5-N1 基础与现代 IT 职场交流必备词）、假名注音精准切换、中文释义、例词关联、答错自动追加至当轮末尾循环强化。
  - **句子听力 (Sentence Practice)**：226 句日常实用对话经典例句盲听盲测、日文汉字/假名注音/中文释义渐进显隐；句中重点核心词汇自动提取标签，与 2039 词库实现 100% 双向关联，支持单点单独发音点读。
  - **真实日常生活会话造句系统**：内置近 200 条经典生活日常面对面会话（`CURATED_DAILY_CONVERSATIONS`），结合 14 大日常生活场景（出行通勤、美食饮品、下厨调料、生病就医、办事机构、服饰穿搭、日程预约等）智能自然造句，彻底根除机械单一模板，全量 2039 个词汇实现 100% 都有地道自然例句辅助听力辨音与语境学习。
  - **假名书写练习 (Kana Board)**：104 个五十音平假名与片假名标准田字格手写练习，支持一笔撤销、清空重写、一键核对标准形态对比与错题本循环复习。
- **全平台高保真发音引擎 & iPad 深度适配**：
  - 支持 **在线真人日语音频** 与 **系统本地 TTS 高保真合成**（完美调用 Apple 原生 Siri / 京子 高保真语音）；
  - 具备**全局首触手势音频解锁**与**防止 iOS 垃圾回收（GC）截断机制**，彻底解决 iPad Safari 锁屏或切题静音问题；
  - **滑动条语速调节**：发音设置中通过滑动条在 `0.8x ~ 1.5x` 范围内平滑微调（步进 `0.05`，附带快捷预设刻度）；
  - 弹窗内置 iPad 静音模式排查指引与单词/句子实时试听。
- **词库管理**：2039 个核心词汇与 226 句经典例句全量呈现，支持关键词模糊搜索、分页浏览与点读发音。
- **云端同步**：接入 Cloudflare KV，永久保存每个单词与句子的艾宾浩斯复习排期。

### 2. ✍️ 汉字听写与笔顺 (`/hanzi`)
- **核心理念**：多感官汉字启蒙、规范笔顺临摹演示与日常听写打卡。
- **全量汉字艾宾浩斯记忆曲线（SM-2）**：
  - 精选 **174 个高频基础生字**，科学划分为“数字数量”、“方位位置”、“自然天文”、“人体器官”、“动物植物”、“日常生活”等生活化分类；
  - 科学复习周期：`Lv.0`（当天复习）➔ `Lv.1`（1天）➔ `Lv.2`（3天）➔ `Lv.3`（7天·已掌握🌟）➔ `Lv.4`（14天）➔ `Lv.5`（30天）➔ `Lv.6+`（60天）；
  - 答错自动标记并追加至当轮末尾循环强化，直到完全掌握。
- **全功能互动手写与笔顺系统**：
  - **田字格手写板**：标准儿童护眼田字格 Canvas 手写板，支持笔画一笔撤销、一键清空重写与答案核对；
  - **规范笔顺动画临摹**：基于 HanziWriter 矢量动态笔画引擎，慢动作逐笔演示规范笔画顺序，支持一笔一划慢速临摹；
  - **字+提示词防混淆语音朗读**：支持“汉字+提示词”智能朗读（如：天，天空的天；清，清水的清），彻底告别同音字混淆困扰；
  - **看字认读与听音选字闯关 (v1.0.13)**：支持点按发音、拼音释义显隐测试；听音选字升级为 5 选项 3+2 对称排版，干扰字从国家标准 3500 常用字库中随机选取并严格排除已学字，固定边框与槽位无缝防位移，支持键盘 1~5 键快捷作答。
- **云端多端同步**：
  - 汉字模块已全面接入后端 Worker（`/api/hanzi/sync`），专属密钥实现手机、平板、电脑间听写打卡进度无缝漫游。

### 3. 🎹 钢琴视奏与识音 (`/music`)
- **核心理念**：专为琴童打造的五线谱视奏启蒙、真实原声钢琴麦克风精准识音与即时纠错。
- **超大字号儿童友好乐谱**：
  - 五线谱行距加大 50%（21px 行距），加粗谱线与高低音谱号，配以特大号音符椭圆，保护儿童视力，完美适配 iPad 放置在钢琴谱架上远距离辨读；
  - 醒目大号目标音名与唱名胶囊徽章（如 `C4 / 中央C (Do)`），支持高音谱号（Treble G4~C5）、低音谱号（Bass C3~F4）一键切换或混合大谱表练习。
- **真实物理钢琴音色合成器**：
  - 基于纯 Web Audio API 动态合成物理泛音（包含基频与 2/3/4 次泛音谐波序列、打击锤敲弦瞬态噪声与双弦微调合唱混响），真实还原三角钢琴延音质感，告别刺耳蜂鸣音；
  - 提供目标音点击「🔊 试听」与答对通关和弦琶音奖励（C5 + G5）。
- **iPad / 移动端高灵敏度拾音与智能音高判定引擎**：
  - **硬件前置放大（Pre-amp）**：内置 +14dB (5x) 软件增益节点，提供多档灵敏度切换（5x iPad 推荐 / 8x 超高增益 / 3x 标准 / 1x 原始），彻底攻克 iPad/iOS 麦克风硬件音量衰减难题；
  - **次谐波与智能泛音容差**：引入次谐波周期分析，有效消除真实钢琴中低音区第 2 谐波强于基频引发的“翻八度”误判；
  - **轻力触键即刻判定**：针对真实钢琴拉尔斯贝克（Railsback）伸缩调律自适应 $\pm 35$ cents 宽容度，小朋友温柔轻弹也能秒级精准识别，彻底告别“重力砸琴才能识别”的烦恼；
  - **实时音准反馈**：动态音分偏移指示卡片与偏高/偏低刻度条（Flat / Sharp），辅助琴童培养绝对音感。
- **本地进度足迹**：自动保存累计练习题数与最高连击记录，并在主门户学习足迹中展示。

### 7. ⚡ SPA 单页 App 架构与 PWA 极速体验 (`v1.0.24`)
- **SPA (Single Page Application) 单页宿主容器架构**：
  - 主门户 `index.html` + `app.js` 充当 App Shell，统一接管四大模块（日语、汉字、钢琴、英语）的路由与容器调度；
  - **多任务模块保活秒开**：通过原生全屏无缝容器保活后台状态与 Web Audio 音频上下文，避免重复加载，二次切入毫无停顿与白屏；
  - **原生 App 级滑动转场**：页面切换配备平滑右进左退动效（`spa-slide-enter`），且深度绑定 Hash 路由（`#/japanese`、`#/hanzi` 等），完美支持手机侧滑手势与安卓物理返回键自然回退；
  - **统一通信与全屏防跳出桥接 (`viewport.js`)**：子模块内部返回主页链接自动捕获并向外层发送 `SPA_NAVIGATE_HOME` postMessage，彻底消除 iOS PWA Standalone 模式跳转弹出 Safari 导航栏或跳出全屏的体验瑕疵。
- **趣味伴学加载卡片与动态微光进度条**：
  - 进入页面时弹出居中萌宠学霸猫咪趣味卡片，展示「正在进入 [模块]...」；
  - 配备圆润糖果胶囊进度条与百分比数值实时递增反馈，全站顶栏同步亮起全局微光流光进度线（`global-page-progress`），动效轻快治愈；
  - 页面加载就绪即刻丝滑展现，告别传统网页跳转的生硬感。
- **PWA 手机/平板桌面安装引导系统**：
  - 接入 `sw.js` (Service Worker) 智能离线缓存，核心资源秒级预热；
  - 首页内置智能环境识别：在 Android Chrome 自动调用原生应用安装横幅；在 iPhone / iPad Safari 自动滑出针对儿童与家长友好的手把手图文引导卡片（点击底栏分享 ➔「添加到主屏幕」）；桌面独立运行时自动隐藏提示。

## 🚀 部署方案

### 方式一：连接 GitHub 自动部署（推荐）

1. **将项目推送到你的 GitHub 仓库**：
   ```bash
   git add .
   git commit -m "feat: release v1.0.4 with unified design system"
   git push
   ```

2. **登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)**：
   - 导航至 **「Workers 和 Pages」** ➔ 点击 **「创建」** ➔ 关联你的 GitHub 仓库；
   - **根目录 (Root directory)**：保持默认 `/`；
   - **构建命令 (Build command)**：留空；
   - **输出目录 (Build output directory)**：填 `.`（根目录）。

3. **绑定 KV 数据库（支持全模块云端同步）**：
   - 在 Cloudflare 控制台左侧菜单 **「KV」** 中创建命名空间 `STUDY_KV`；
   - 进入你的 Worker 设置 ➔ **「设置」** ➔ **「绑定 (Bindings)」** ➔ 添加 KV 绑定：
     - **变量名称 (Variable name)**：`STUDY_KV`
     - **KV 命名空间**：选择绑定的 `STUDY_KV`。

---

### 方式二：使用 Wrangler 命令行一键部署

在项目根目录下执行：
```bash
# 1. 安装项目依赖并登录 Cloudflare 账号
npm install
npx wrangler login

# 2. 本地开发预览（支持本地模拟 KV 与 API 路由）
npm run dev

# 3. 直接部署发布到 Cloudflare 全球边缘网络
npm run deploy
```

## 📱 移动端与 iPad 使用技巧

1. **添加到主屏幕（全屏 App 纯净体验）**：
   - **iPad / iPhone Safari**：点击右上角或底部的「分享」按钮 ➔ 选择「添加到主屏幕」；
   - **Android Chrome**：点击右上角菜单 ➔ 选择「安装应用」或「添加到主屏幕」；
   - 启动后自动隐藏地址栏与底部按钮，字体更大、排版更舒展，彻底消除上下滚动留白！

2. **多端进度同步设置**：
   - 在日语或汉字模块顶部点击 **「☁️ 云同步」**；
   - 输入专属 **同步密钥 (Sync Key)**（如 `baby888` 或自定义字母口令）；
   - 在所有设备上填入相同密钥并开启「自动同步」，学习进度、到期排期、错题本即可实时互通。

3. **版本自动感知与智能刷新**：
   - 首页顶部右上角常驻当前运行版本号（如 `v1.0.24`）；
   - 当发布新版本后，首页顶部将自动滑出动态通知横幅，点击「🚀 立即更新」即可将新版本持久化记录至本地、清理缓存并携带最新版本戳瞬时刷新，彻底消除死循环提示问题。
