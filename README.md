# Study Hub · 语言与识字综合学习中心

> 基于 **Cloudflare 全栈架构 (Workers + KV + Assets)** 构建的多合一轻量化自学平台，包含日语、汉字、英语等多语言与学习技能模块。

无需自建服务器，依托 Cloudflare 全球边缘网络与分布式 KV 数据库，实现：
- 🌐 **全球极速访问**：免运维、自带免费 HTTPS 与自定义域名支持；
- 🧠 **科学记忆算法**：全面采用**艾宾浩斯（SM-2）间隔重复遗忘曲线**，科学规划复习周期；
- 📱 **多端全自动同步**：手机、平板、电脑通过专属密钥（Sync Key）实时同步刷题与复习进度；
- 🍎 **移动端/iPad 深度适配**：支持 PWA/添加到主屏幕全屏运行，针对 iOS/iPadOS WebKit 音频与手势进行了全方位深度优化。

## 📚 模块功能详解

### 1. 🎌 日语听力与词汇 (`/japanese`)
- **核心理念**：“听力优先”盲测设计，通过声音直接刺激大脑反应，告别“哑巴日语”。
- **双大练习模式**：
  - **单词听力 (Word Practice)**：盲听识别、假名注音精准发音切换、中文释义、例词关联、答错自动加入当轮末尾循环重练。
  - **句子听力 (Sentence Practice)**：120 句日常高频对话表达，整句盲听盲测、拼音注音/中文释义渐进显隐、句中重点核心词汇高亮并支持单点发音。
- **全平台发音引擎 & iPad 深度适配**：
  - 支持 **在线真实日语音频** 与 **系统本地 TTS 合成**（iPad/iPhone 搭载 Apple 原生 Siri / 京子 高保真语音）；
  - 句子朗读直连高保真系统 TTS，语调自然、断句准确且无网络延迟；
  - 配备**全局首触手势音频解锁器**与**防止 iOS 垃圾回收（GC）截断机制**，彻底解决 iPad Safari 锁屏或切题静音问题；
  - **滑动条语速调节**：支持在发音设置中通过滑动条在 `0.8x ~ 1.5x` 范围内平滑微调（步进 `0.05`，附带快捷刻度锚点）；
  - 设置弹窗内置 iPad 静音模式排查指引与单词/句子双向试听。
- **词库管理**：1780+ 核心进阶词汇与 120 句会话，支持自定义增删改查、释义编辑、批量导入与导出 JSON。
- **云端同步**：接入 Cloudflare KV，永久保存每个单词与句子的艾宾浩斯复习时间戳。

---

### 2. ✍️ 汉字听写与笔画 (`/hanzi`)
- **核心理念**：多感官汉字启蒙、日常听写与规范书写。
- **全量汉字艾宾浩斯记忆曲线（SM-2）**：
  - 收录 187 个基础生字，初始状态已全部自动初始化为已学过（`Lv.1`）并进入复习周期；
  - 科学复习间隔：`Lv.0`（当天立即复习）➔ `Lv.1`（1天）➔ `Lv.2`（3天）➔ `Lv.3`（7天·已掌握🌟）➔ `Lv.4`（14天）➔ `Lv.5`（30天）➔ `Lv.6+`（60天）；
  - **答错循环重练**：听写或认读记错时，立即重置为 `Lv.0` 并自动追加至本轮末尾重练，直到当轮完全掌握。
- **首页看板与智能推荐**：
  - 醒目展示「今日艾宾浩斯复习」提示卡与「⚡ 立即复习」快捷按钮；
  - 4 格动态看板实时汇总：**今日待复习**、**已掌握 (Lv.3+)**、**错字数量**、**累计练习**；
  - 练习范围下拉框默认智能置顶推荐今日到期汉字。
- **丰富互动学习模式**：
  - **手写听写**：支持标准田字格 Canvas 手写、撤销笔画、写完核对，并预测下次复习排期；
  - **笔顺演示与临摹**：基于 HanziWriter 的矢量动态笔画动画，直观展示笔顺笔画；
  - **看字认读**：看字自读、点按发音、拼音释义显隐；
  - **听音选字**：趣味选字测试，答错即时反馈；
  - **随机阅读**：短句故事阅读与跟读。
- **云端同步与后端接入**：
  - 汉字模块已全面接入后端 Worker（`/api/hanzi/sync`），专属密钥同步听写进度、错字本与笔顺记录。

## 📁 目录结构与后端架构

项目后端采用**模块化路由架构**，将各学习模块的同步逻辑独立分拆，统一由入口 Worker 分发：

```text
study/
├── backend/
│   ├── worker.js              # 🌟 统一主后端入口（负责路由分发与全站静态网页托管）
│   └── routes/
│       ├── japanese.js        # 🎌 日语模块 KV 云同步路由 (/api/japanese/sync, /api/sync)
│       └── hanzi.js           # ✍️ 汉字模块 KV 云同步路由 (/api/hanzi/sync)
├── index.html                 # 🎓 学习中心总导航门户 (Study Hub 首页)
├── japanese/                  # 🎌 日语学习模块
│   ├── frontend/
│   │   ├── index.html         # 单页应用 (Vue 3 + Tailwind CSS)
│   │   ├── vocab_data.js      # 1780+ 词汇核心题库
│   │   └── sentence_data.js   # 120 句日常高频对话题库
│   └── docs/                  # 原始词汇归档与文档
├── hanzi/                     # ✍️ 汉字听写模块
│   ├── hanzi.html             # 汉字主应用页面
│   ├── hanzi.css              # 样式定义（含移动端自适应与艾宾浩斯组件）
│   ├── hanzi.js               # 业务逻辑（艾宾浩斯复习调度、手写画板、云同步）
│   └── hanzi-data.js          # 基础汉字库与笔顺数据
├── english/                   # 🔤 英语词卡模块
│   └── english.html           # 翻转卡片学习页面
├── wrangler.toml              # 🚀 Cloudflare Worker 与 KV 绑定配置文件
├── package.json               # 📦 项目依赖与脚本配置
├── .assetsignore              # 🛡️ 静态资源上传过滤规则
└── README.md                  # 📖 项目总说明文档
```

## 🚀 部署方案

### 方式一：连接 GitHub 自动部署（推荐）

1. **将项目推送到你的 GitHub 仓库**：
   ```bash
   git add .
   git commit -m "feat: update study hub"
   git push
   ```

2. **登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)**：
   - 导航至 **「Workers 和 Pages」** ➔ 点击 **「创建」** ➔ 选择 **「Pages」** 或 **「Workers」** 关联你的 GitHub 仓库；
   - **根目录 (Root directory)**：保持默认 `/`；
   - **构建命令 (Build command)**：留空；
   - **输出目录 (Build output directory)**：填 `.`（根目录）。

3. **绑定 KV 数据库（支持全模块云端同步）**：
   - 在 Cloudflare 控制台左侧菜单 **「KV」** 中创建命名空间 `STUDY_KV`；
   - 进入你的项目设置 ➔ **「设置」** ➔ **「绑定 (Bindings)」** ➔ 添加 KV 绑定：
     - **变量名称 (Variable name)**：`STUDY_KV`
     - **KV 命名空间**：选择绑定的 `STUDY_KV`。

---

### 方式二：使用 Wrangler 命令行一键部署

在项目根目录下执行：
```bash
# 1. 安装项目依赖并登录 Cloudflare 账号
npm install
npx wrangler login

# 2. 本地开发预览（支持本地模拟 KV 与 API 路由）
npm run dev

# 3. 直接部署发布到 Cloudflare 边缘网络
npm run deploy
```

## 📱 移动端与 iPad 使用贴士

1. **添加到主屏幕（全屏 App 体验）**：
   - **iPad / iPhone Safari**：点击工具栏的「分享」按钮 ➔ 选择「添加到主屏幕」；
   - **Android Chrome**：点击右上角菜单 ➔ 选择「安装应用」或「添加到主屏幕」；
   - 启动后自动隐藏浏览器导航条，享受原生 App 级沉浸式全屏刷题体验。

2. **多端进度同步设置**：
   - 在日语模块或汉字模块顶部点击 **「☁️ 云同步」**；
   - 设置专属 **同步密钥 (Sync Key)**（如 `my-study-2026`）；
   - 在手机、平板、电脑等各个设备上填入相同密钥并勾选「自动实时同步」，所有做题进度、艾宾浩斯等级、错题本即刻跨端对齐。

3. **iPad 发音排查提示**：
   - 若在 iPad 上听不到发音，请从**屏幕右上角向下滑动调出「控制中心」**，检查**红色的「静音模式（铃铛图标）」**是否处于开启状态（开启静音模式会导致系统发音静音）；
   - 保证 iPad 处于非静音状态并将媒体音量适度调大即可完美发音。
