# Study Hub · 语言与识字综合自学中心

> 基于 **Cloudflare 全栈架构 (Workers + KV + Assets)** 构建的多合一轻量化自学平台，包含日语、汉字、英语等多语言与学习技能模块。

无需自建复杂服务器，依托 Cloudflare 全球边缘网络与分布式 KV 数据库，实现：
- 🌐 **全球极速访问**：纯前端轻量化静态页面，秒级即开即学，免运维且自带免费 HTTPS；
- 🧠 **科学记忆算法**：全面采用**艾宾浩斯（SM-2）间隔重复遗忘曲线**，科学规划复习周期；
- 📱 **多端全自动同步**：手机、平板、电脑通过专属密钥（Sync Key）跨设备实时同步刷题与复习进度；
- 👶 **儿童友好护航设计**：全局 3D 立体触感大按键、统一的儿童防误触二次确认与柔和气泡提醒（`kid-dialog.js`）；
- 🍎 **移动端 / iPad 深度适配**：支持 PWA / 添加到主屏幕全屏运行，针对 iOS/iPadOS Safari 视口上移、留白 bug 及 WebKit 音频进行了全方位深度优化；
- 🔄 **自动感知平滑更新**：内置版本监测机制（方案 C），新版发布后在首页无感感知并提醒一键击穿缓存刷新。

## 📚 模块功能详解

### 1. 🎌 日语听力与假名 (`/japanese`)
- **核心理念**：“听力优先”盲测设计，通过声音直接刺激大脑反应，告别“哑巴日语”。
- **三大核心功能模式**：
  - **单词听力 (Word Practice)**：1912 个核心高频词汇盲听测试、假名注音精准切换、中文释义、例词关联、答错自动追加至当轮末尾循环强化。
  - **句子听力 (Sentence Practice)**：226 句日常实用对话例句盲听盲测、日文汉字/假名注音/中文释义渐进显隐；句中重点核心词汇自动提取标签，支持单点单独发音点读。
  - **假名书写练习 (Kana Board)**：104 个五十音平假名与片假名标准田字格手写练习，支持一笔撤销、清空重写、一键核对标准形态对比与错题本循环复习。
- **全平台高保真发音引擎 & iPad 深度适配**：
  - 支持 **在线真人日语音频** 与 **系统本地 TTS 高保真合成**（完美调用 Apple 原生 Siri / 京子 高保真语音）；
  - 具备**全局首触手势音频解锁**与**防止 iOS 垃圾回收（GC）截断机制**，彻底解决 iPad Safari 锁屏或切题静音问题；
  - **滑动条语速调节**：发音设置中通过滑动条在 `0.8x ~ 1.5x` 范围内平滑微调（步进 `0.05`，附带快捷预设刻度）；
  - 弹窗内置 iPad 静音模式排查指引与单词/句子实时试听。
- **词库管理**：1912 个核心词汇与 226 句例句全量呈现，支持关键词模糊搜索、分页浏览与点读发音。
- **云端同步**：接入 Cloudflare KV，永久保存每个单词与句子的艾宾浩斯复习排期。

### 2. ✍️ 汉字听写与笔顺 (`/hanzi`)
- **核心理念**：多感官汉字启蒙、规范笔顺临摹演示与日常听写打卡。
- **全量汉字艾宾浩斯记忆曲线（SM-2）**：
  - 精选 **170 个高频基础生字**，科学划分为“数字数量”、“方位位置”、“自然天文”、“人体器官”、“动物植物”、“日常生活”等生活化分类；
  - 科学复习周期：`Lv.0`（当天复习）➔ `Lv.1`（1天）➔ `Lv.2`（3天）➔ `Lv.3`（7天·已掌握🌟）➔ `Lv.4`（14天）➔ `Lv.5`（30天）➔ `Lv.6+`（60天）；
  - 答错自动标记并追加至当轮末尾循环强化，直到完全掌握。
- **全功能互动手写与笔顺系统**：
  - **田字格手写板**：标准儿童护眼田字格 Canvas 手写板，支持笔画一笔撤销、一键清空重写与答案核对；
  - **规范笔顺动画临摹**：基于 HanziWriter 矢量动态笔画引擎，慢动作逐笔演示规范笔画顺序，支持一笔一划慢速临摹；
  - **字+提示词防混淆语音朗读**：支持“汉字+提示词”智能朗读（如：天，天空的天；清，清水的清），彻底告别同音字混淆困扰；
  - **看字认读与听音选字**：支持点按发音、拼音释义显隐测试及趣味选字闯关。
- **云端多端同步**：
  - 汉字模块已全面接入后端 Worker（`/api/hanzi/sync`），专属密钥实现手机、平板、电脑间听写打卡进度无缝漫游。

### 3. 🔤 英语核心动词卡 (`/english`)
- **核心理念**：最基础、最高频的日常动词与情态动词强化记忆。
- **功能特性**：
  - **100 个核心高频生活动词**：涵盖日常行动、感官认知、情感沟通等必备核心词卡；
  - **3D 双面立体翻牌卡片**：正面中文释义联想，轻触翻转背面揭晓英文拼写与自动语音朗读；
  - **掌握度即时决策**：“已掌握 / 认识” 与 “需复习 / 没记住” 双大键判定，自动更新掌握度统计；
  - **进度圆环看板与分类筛选**：实时展示掌握率百分比环形进度条，支持在全部、已掌握、需复习列表中筛选点读复习；
  - **键盘快捷操作**：支持键盘 `← / →` 快速切词、`空格键` 翻转卡片、`1` 键不认识、`2` 键认识。

### 4. 🎨 全局儿童护航系统与统一设计规范
- **统一弹窗与提示 (`kid-dialog.js`)**：
  - 彻底移除了浏览器原生突兀的 `alert()` / `confirm()`；
  - 统一由圆润柔和的卡片式弹窗接管：支持 `kidAlert`（通知）、`kidConfirm`（双键确认）、`kidToast`（微反馈气泡）与 `kidConfirmExitPractice`（退出练习防误触确认）；
- **统一界面尺寸与 3D 触控大按钮**：
  - 顶栏高度（`h-9` + 安全区）、返回首页按键（胶囊 Pill 形状 `🏠 首页`，无干扰直接跳转）；
  - 底栏高度（`h-16 items-center`，带激活指示横条与动态复习角标）；
  - 题目掌握判定决策组统一采用双列大按键（`py-3.5 sm:py-4 kid-btn-danger` 与 `kid-btn-success`）；
  - 弹窗均采用底部滑出式抽屉大圆角卡片（`!rounded-t-3xl`）与右上角圆形关闭纽扣（`✕`）。
- **首页动态“学习足迹”看板**：
  - 首页根据用户本地真实练习数据，自动计算各模块已学、已掌握进度与今日到期待复习提醒（如：`已学 45 词 · 掌握 18 词 · ⏰ 5 待复习`）。

## 🚀 部署方案

### 方式一：连接 GitHub 自动部署（推荐）

1. **将项目推送到你的 GitHub 仓库**：
   ```bash
   git add .
   git commit -m "feat: release v1.0.4 with unified design system"
   git push
   ```

2. **登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)**：
   - 导航至 **「Workers 和 Pages」** ➔ 点击 **「创建」** ➔ 关联你的 GitHub 仓库；
   - **根目录 (Root directory)**：保持默认 `/`；
   - **构建命令 (Build command)**：留空；
   - **输出目录 (Build output directory)**：填 `.`（根目录）。

3. **绑定 KV 数据库（支持全模块云端同步）**：
   - 在 Cloudflare 控制台左侧菜单 **「KV」** 中创建命名空间 `STUDY_KV`；
   - 进入你的 Worker 设置 ➔ **「设置」** ➔ **「绑定 (Bindings)」** ➔ 添加 KV 绑定：
     - **变量名称 (Variable name)**：`STUDY_KV`
     - **KV 命名空间**：选择绑定的 `STUDY_KV`。

---

### 方式二：使用 Wrangler 命令行一键部署

在项目根目录下执行：
```bash
# 1. 安装项目依赖并登录 Cloudflare 账号
npm install
npx wrangler login

# 2. 本地开发预览（支持本地模拟 KV 与 API 路由）
npm run dev

# 3. 直接部署发布到 Cloudflare 全球边缘网络
npm run deploy
```

## 📱 移动端与 iPad 使用技巧

1. **添加到主屏幕（全屏 App 纯净体验）**：
   - **iPad / iPhone Safari**：点击右上角或底部的「分享」按钮 ➔ 选择「添加到主屏幕」；
   - **Android Chrome**：点击右上角菜单 ➔ 选择「安装应用」或「添加到主屏幕」；
   - 启动后自动隐藏地址栏与底部按钮，字体更大、排版更舒展，彻底消除上下滚动留白！

2. **多端进度同步设置**：
   - 在日语或汉字模块顶部点击 **「☁️ 云同步」**；
   - 输入专属 **同步密钥 (Sync Key)**（如 `baby888` 或自定义字母口令）；
   - 在所有设备上填入相同密钥并开启「自动同步」，学习进度、到期排期、错题本即可实时互通。

3. **版本自动感知与刷新**：
   - 首页顶部右上角常驻版本号（如 `v1.0.4`）；
   - 当云端发布新版本后，首页顶部将自动滑出动态通知横幅，点击「🚀 立即更新」即可自动带时间戳击穿磁盘缓存，瞬间载入最新功能。
