# 项目需求：钢琴视奏与音高检测 Web 应用

你好！请帮我编写一个基于 Web 技术的单页面应用（SPA）。这个应用的主要功能是：在网页上显示五线谱和随机音符，然后通过设备的麦克风（特别是 iPad）监听用户在真实钢琴上弹奏的声音。如果用户弹奏的音符与五线谱显示的音符一致，则判定正确并自动切换到下一个音符。

## 1. 核心功能需求

*   **五线谱显示**：在屏幕中央清晰地显示标准的五线谱（高音谱号或低音谱号）。
*   **随机出题**：应用启动后，随机在五线谱上生成一个音符（例如中央 C，即 Do）。
*   **麦克风监听**：请求用户的麦克风权限，实时捕获环境声音。
*   **音高检测 (Pitch Detection)**：分析麦克风输入的音频流，识别出当前弹奏的具体音高（频率），并将其转换为对应的音符（如 C4, D4 等）。
*   **验证与反馈**：
    *   如果检测到的音符与目标音符一致（持续一小段时间，避免杂音误判），则给出“正确”的视觉反馈（例如音符变绿）。
    *   正确后，自动刷新五线谱，随机显示下一个新的音符。

## 2. 技术栈建议

由于需要纯前端实现，建议使用以下技术组合：
*   **基础框架**：原生 HTML/CSS/JavaScript，或者 React（单文件形式即可）。
*   **五线谱渲染**：强烈建议使用 **VexFlow** (`vexflow.js`) 库，这是业界标准的 Web 五线谱渲染库。
*   **音频处理**：使用 HTML5 **Web Audio API**。
*   **音高检测算法**：建议使用现成的库，例如 **ml5.js (Pitch Detection)** 或 **Pitchfinder.js**。如果不依赖外部库，请实现基于自相关（Autocorrelation）算法的音高检测。

## 3. 关键设备兼容性要求（针对 iPad/iOS Safari）

这是一个**非常重要**的限制条件：
*   **AudioContext 策略**：iOS Safari 严格限制自动播放和录音。必须在界面上提供一个显式的“开始练习”按钮，**只有在用户点击该按钮的回调函数中**，才能初始化并调用 `AudioContext.resume()` 和请求 `navigator.mediaDevices.getUserMedia`。
*   **HTTPS 协议**：麦克风 API 只能在 HTTPS 环境或 localhost 下工作，请在代码注释中提醒我这一点。

## 4. 界面 (UI/UX) 需求

*   **简洁美观**：适合 iPad 横屏或竖屏查看。
*   **顶部/居中**：一个大大的“开始/开启麦克风”按钮。
*   **中部**：宽大的五线谱区域，显示的音符要足够大，方便视奏。
*   **底部状态栏**：显示当前麦克风状态（未连接/收音中）、当前识别到的音符（例如：“听到：D4”），方便调试。
*   **容错处理**：钢琴声音有泛音，且频率可能并非绝对精准，请在频率匹配时设置合理的容差范围（例如 $\pm 10$ cents）。

## 5. 代码输出要求

*   请将所有的 HTML、CSS 和 JavaScript 逻辑打包输出在**一个单一的 `.html` 文件**中，以便我可以直接下载并在浏览器中运行测试。
*   代码必须包含详细的中文注释，特别是音高频率映射表（如 C4 = 261.63 Hz）和音频处理的核心逻辑部分。

请根据以上需求，生成完整的代码。
